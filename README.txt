راهنمای راه‌اندازی:
1) در Supabase یک پروژه بساز.
2) فایل schema.sql را در SQL Editor اجرا کن.
3) URL و anon key پروژه را داخل supabase.js قرار بده.
4) فایل‌های index.html و supabase.js را روی یک hosting استاتیک مثل Vercel/Netlify قرار بده.
5) برای ورود برگزارکننده، Email Auth در Supabase فعال باشد.
نکته: anon key برای فرانت‌اند طراحی شده؛ service_role key را هرگز داخل سایت قرار نده.
